# Captures d'écran du README

Déposer ici les PNG puis les référencer dans le README racine.

Captures qui mettent le projet en valeur (app lancée sur http://localhost:3000) :

| Fichier attendu | Ce qu'il faut cadrer |
|---|---|
| `pitch.png` | Vue caméra TV large : le stade, les 22 joueurs, le ballon en jeu |
